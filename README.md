# Sconto SoMe M2M Report

Statická Vite React SPA pro MoM report výkonu instagramových postů Sconto CZ/SK.

## Lokální vývoj

```bash
pnpm install
pnpm run dev
```

## Build a náhled

```bash
pnpm run build
pnpm run preview
```

Build generuje klasický statický výstup:

```text
dist/index.html
dist/assets/...
```
